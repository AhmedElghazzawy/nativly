Plan the next step. Don't write code in this turn.

1. Read docs/learning/PROGRESS.md and the relevant phase in docs/build-plan.md.
2. Pick the smallest next step that is useful on its own and testable (30–60 min of work).
3. Present it as:
   - **Goal** (one line)
   - **Concept you'll learn** (name it, explain in 2–3 sentences, and why professionals care)
   - **Plan** (3–6 numbered steps; mark which ones the learner writes ✍️ and which Claude writes)
   - **Done when** (the test or command that proves it works)
   - **Out of scope** (what we're deliberately not doing yet)
4. Ask: "Any questions about the concept before we start?"
